# Cloud Fintech Journey 2026
This repository documents a 16 week transtion project plan to transition into cloud infrastructure engineering with a primary focus on fintech-grade systems.
## Goal
To build production-level skills in:
-AWS cloud infrastructure
-IaaC with Terraform
-Linux SA
-Cloud security and reliability engineering

##Background 

This project is part of a structured training path transitioning from typical enterprise systems administration and engineering to cloud and platform engineering.

##Technologies covered

-AWS (EC2,VPC,IAM, S3,CloudWatch)
-Linux (Ubuntu, RHEL)
-Terraform (for IaaC)
-Networking 
-Security best practices

## Structure 

Each folder represents one week of hand on infrastructure work, to include:
-deployed systems
-architecture notes
-incident simulations
-documentation of failures and fixes

##Disclaimer

This is a learning/porfolio project. All infrastructure is built using free-tier cloud resources where applicable.
